# Auditoria de rendimiento web

## Propósito

Identificar cuellos de botella y proponer mejoras medibles de rendimiento web.

## Cuándo utilizarla

- Un sitio presenta lentitud o necesita una línea base.

## Cuándo no utilizarla

- No existe permiso para medir el entorno objetivo.

## Información necesaria

- URLs, dispositivos, mercados, analítica disponible y objetivos de rendimiento.

## Procedimiento

1. Define paginas, dispositivos, ubicaciones y condiciones de prueba.
2. Captura metricas de laboratorio y datos reales cuando existan.
3. Analiza red, renderizado, JavaScript, imagenes, fuentes y terceros.
4. Relaciona cada problema con evidencia y efecto sobre usuarios.
5. Prioriza por impacto, esfuerzo y riesgo; repite mediciones tras los cambios.

## Validación

- Cada hallazgo o decisión tiene evidencia y responsable.
- Los criterios de exito se comprueban antes de cerrar la tarea.
- Las desviaciones quedan registradas con su siguiente accion.

## Resultado esperado

Linea base, causas verificadas y plan priorizado con metricas objetivo.

## Seguridad

Nivel de riesgo: **low**. No ejecutes cambios irreversibles, accesos a producción ni operaciones con credenciales sin autorización explícita, copia recuperable y plan de reversa.
