# Preparación de proyecto web

## Propósito

Preparar una base web mantenible con decisiones, estructura y controles iniciales.

## Cuándo utilizarla

- Un proyecto nuevo necesita una base técnica repetible.

## Cuándo no utilizarla

- El alcance y la tecnologia aun no han sido acordados.

## Información necesaria

- Objetivos, usuarios, restricciones, stack aprobado y criterios de entrega.

## Procedimiento

1. Confirma alcance, responsables y restricciones antes de elegir herramientas.
2. Inspecciona los estandares existentes y reutilizalos cuando sean aplicables.
3. Crea la estructura minima, configuración de entorno y comandos de desarrollo.
4. Anade controles de formato, pruebas, build y documentación de arranque.
5. Registra decisiones relevantes y valida el flujo desde una clonacion limpia.

## Validación

- Cada hallazgo o decisión tiene evidencia y responsable.
- Los criterios de exito se comprueban antes de cerrar la tarea.
- Las desviaciones quedan registradas con su siguiente accion.

## Resultado esperado

Repositorio inicial, convenciones, comandos verificables y registro de decisiones.

## Seguridad

Nivel de riesgo: **low**. No ejecutes cambios irreversibles, accesos a producción ni operaciones con credenciales sin autorización explícita, copia recuperable y plan de reversa.
