# Primeros pasos

## Objetivo

Este repositorio funcióna como fuente comun de procedimientos para personas y agentes de IA. Las skills se seleccionan por ID, categoría o etiquetas y se adaptan al consumidor sin modificar su contenido canónico.

## Flujo recomendado

1. Busca una skill en `catalog/es/README.md`.
2. Revisa su nivel de riesgo y capacidades.
3. Lee `skills/<categoría>/<id>/locales/es/SKILL.md`.
4. Aporta el contexto solicitado por la skill.
5. Ejecuta el procedimiento y sus validaciónes.
6. Registra mejoras en la fuente canonica y regenera los adaptadores.

## Regla de idiomas

Los titulos y textos visibles siempre corresponden al idioma seleccionado. Los IDs técnicos no se traducen para que las referencias sean estables.
