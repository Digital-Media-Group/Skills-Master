# Lista de revisión

- El ID y la ruta coinciden.
- Los titulos estan en el idioma correcto.
- Espanol e ingles cubren el mismo alcance.
- Las entradas y salidas son claras.
- El procedimiento tiene orden y condiciones de parada.
- La validación demuestra el resultado.
- Los riesgos y acciones destructivas estan declarados.
- No hay secretos ni datos de clientes.
