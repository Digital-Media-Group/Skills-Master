# Getting Started

## Purpose

This repository is a shared source of procedures for people and AI agents. Skills are selected by ID, category, or tags and adapted to each consumer without changing canonical content.

## Recommended Flow

1. Find a skill in `catalog/en/README.md`.
2. Review its risk level and capabilities.
3. Read `skills/<category>/<id>/locales/en/SKILL.md`.
4. Provide the context requested by the skill.
5. Execute the procedure and its validation steps.
6. Record improvements in the canonical source and rebuild adapters.

## Language Rule

Visible titles and text always match the selected locale. Technical IDs are not translated, keeping references stable.
