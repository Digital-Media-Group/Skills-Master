# Codigo de conducta / Code of Conduct

Este proyecto adopta un entorno abierto, respetuoso y libre de acoso. Se espera que toda contribución sea profesional, constructiva y respetuosa con personas de cualquier origen, identidad y nivel de experiencia.

This project maintains an open, respectful, harassment-free environment. Every contribution must be professional, constructive, and respectful toward people of all backgrounds, identities, and experience levels.

Reporta incidentes de forma privada a los responsables del repositorio. Los responsables podran moderar o retirar contenido y limitar la participacion cuando sea necesario para proteger a la comunidad.
