# Adaptador de Claude Code / Claude Code Adapter

Ejecuta `npm run build:adapters` para generar una carpeta por skill e idioma en `dist/claude-code/`. Copia las carpetas del idioma elegido al directorio de skills que use tu instalacion de Claude Code.

Run `npm run build:adapters` to generate one directory per skill and locale under `dist/claude-code/`. Copy the selected locale directories into the skills directory used by your Claude Code installation.
