# Adaptador de OpenAI Codex / OpenAI Codex Adapter

Ejecuta `npm run build:adapters` para generar un `AGENTS.md` autocontenido en `dist/openai-codex/es/` y `dist/openai-codex/en/`. Copia el archivo del idioma elegido a la raiz del proyecto consumidor como `AGENTS.md`.

Run `npm run build:adapters` to generate a self-contained `AGENTS.md` under `dist/openai-codex/es/` and `dist/openai-codex/en/`. Copy the selected locale file to the consumer project root as `AGENTS.md`.
