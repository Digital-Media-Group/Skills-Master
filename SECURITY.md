# Seguridad / Security

No publiques vulnerabilidades, credenciales, datos personales ni información de clientes en issues publicos.

Do not publish vulnerabilities, credentials, personal data, or customer information in public issues.

Para informar de un problema, utiliza el canal privado de seguridad del proveedor donde se aloje el repositorio. Incluye la skill afectada, impacto, pasos de reproducción y mitigaciones conocidas.

Las skills con `riskLevel: high` requieren revisión manual antes de publicarse o ejecutarse en sistemas reales.
